크리스마스 댄스 연습실 - 사용법
================================

[처음 실행하기]
1. 이 폴더를 통째로 원하는 곳(예: 바탕화면)에 둡니다.
2. Start_DancePractice.bat 를 더블클릭합니다.
3. 검은 창이 뜨고, 잠시 뒤 브라우저(크롬/엣지)에서 연습실이 열립니다.
4. 연습하는 동안 검은 창은 닫지 마세요. 다 쓰면 검은 창을 닫으면 끝납니다.

[보안 경고가 뜰 때]
- "Windows의 PC 보호" 창이 뜨면: "추가 정보" -> "실행" 을 누르세요.
- 미리 막으려면: 압축을 풀기 전에 zip 파일을 오른쪽 클릭 -> 속성 -> 아래쪽 "차단 해제" 체크 -> 확인.
- 백신 프로그램이 막으면 이 폴더를 예외로 등록하거나, 아래 [MP4로만 쓰기] 방법을 쓰세요.

[MP4로만 쓰기]
- dance_practice.html 을 바로 더블클릭해도 열립니다.
- 이 경우 유튜브는 재생되지 않고(오류 153), "MP4 파일 열기"로 영상 파일을 열어서 연습합니다.
- 인터넷이 없는 곳에서도 MP4 파일로는 연습할 수 있습니다.

[알아두기]
- 유튜브 영상은 인터넷이 연결되어 있어야 재생됩니다.
- 구간, 연습 완료 체크, 메모는 이 컴퓨터의 브라우저에 저장됩니다.
  다른 컴퓨터로 기록이 옮겨지지는 않습니다.
- 주소(http://localhost:8765/...)가 바뀌면 기록이 따로 저장됩니다.
  보통은 항상 같은 주소로 열립니다.
- 파일들은 같은 폴더 안에 함께 있어야 합니다.

[파일 설명]
- Start_DancePractice.bat : 더블클릭해서 실행하는 파일
- server.ps1               : 이 컴퓨터 안에서만 쓰는 작은 웹서버 (다른 컴퓨터는 접속할 수 없음)
- dance_practice.html     : 연습실 프로그램
