# 바탕화면 캘린더 위젯 (구글 캘린더)

윈도우 바탕화면에 띄워 두는 작은 캘린더 창입니다. 구글 캘린더와 직접 연결되어
위젯에서 **일정 추가 · 수정 · 삭제**를 하면 휴대폰 구글 캘린더에도 바로 반영되고 알림도 그대로 옵니다.

> "크리스마스 댄스 연습실" 프로그램과는 별개의 독립된 프로그램입니다. 코드나 설정을 공유하지 않습니다.

## 기능

- **월 / 주 / 오늘 탭**: 처음엔 월 달력, 위쪽 탭으로 바꿀 수 있습니다. `‹ ›`로 이동, `오늘`로 복귀 (키보드 ← → 도 됨)
- **빠른 추가** (아래 입력칸, 선택한 날짜에 들어감)
  - `14:00 회의`, `오후 2시 30분 방문`, `2시반 상담` → 1시간짜리 일정
  - `내일 9시 교육`, `모레 보고서 마감` → 내일/모레 날짜로
  - 시간이 없으면 종일 일정
  - 오전/오후 없이 1~7시라고 쓰면 **오후**로 봅니다. 새벽이면 `오전 5시` 또는 `05:00`처럼 쓰세요.
- **일정 수정 / 삭제**: 일정을 누르면 제목, 종일 여부, 날짜, 시간, 메모, 알림(10분 전, 1시간 전, 하루 전 등)을 바꾸거나 삭제할 수 있습니다.
  - 반복 일정은 누른 그 날짜 하나만 바뀌거나 지워집니다. 반복 전체를 바꾸려면 "구글에서 열기"를 누르세요.
- 월 달력에서 날짜를 **두 번 클릭**하면 그 날짜에 새 일정 추가
- 5분마다, 그리고 위젯을 다시 클릭할 때 자동 새로고침
- 설정(⚙): 윈도우 시작 시 자동 실행, 항상 위에 표시(📌), 투명도
- 창 위치와 크기는 기억됩니다. 제목줄을 끌어서 옮기고, 가장자리를 끌어서 크기를 바꿉니다.

## 1. 설치 / 실행

PC에 [Node.js](https://nodejs.org/) (LTS)가 있어야 합니다.

```bat
cd calendar_widget
npm install
npm run demo          :: 테스트 데이터로 화면만 확인 (구글 연결 없음)
npm start             :: 실제 구글 캘린더 연결
npm run package:win   :: dist\CalendarWidget-win32-x64\CalendarWidget.exe 생성
```

**윈도우 시작 시 자동 실행**은 `npm run package:win`으로 만든 `CalendarWidget.exe`를 실행했을 때만 설정할 수 있습니다.
`dist\CalendarWidget-win32-x64` 폴더를 원하는 곳(예: `C:\Programs\`)으로 옮긴 다음 그 안의 exe를 실행하고, ⚙ 설정에서 켜 주세요.
(폴더를 옮긴 후에는 자동 실행을 껐다가 다시 켜야 새 위치가 등록됩니다.)

## 2. 구글 설정 (처음 한 번, 약 10분)

위젯이 내 구글 캘린더에 접근하려면 "내 전용 앱 등록증"(OAuth 클라이언트)이 필요합니다.
구글 화면 문구는 바뀔 수 있어 아래 이름과 조금 다를 수 있습니다.

1. https://console.cloud.google.com/ 에 캘린더를 쓰는 구글 계정으로 로그인
2. 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 예: `calendar-widget` → 만들기
3. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → `Google Calendar API` 검색 → **사용**
4. **API 및 서비스 → OAuth 동의 화면**(또는 "Google 인증 플랫폼")
   - 사용자 유형: **외부** → 앱 이름(예: 캘린더 위젯), 지원 이메일, 개발자 연락처 이메일에 내 이메일 입력
   - 범위(scope)는 따로 추가하지 않아도 됩니다.
   - **대상(테스트 사용자)** 에 내 구글 계정 이메일 추가
   - **게시 상태**를 **"앱 게시(프로덕션)"** 로 바꾸는 것을 권장합니다.
     "테스트" 상태로 두면 **7일마다 로그인이 풀려** 다시 로그인해야 합니다.
     프로덕션으로 바꿔도 구글 심사는 필요 없고(나만 쓰는 경우), 로그인할 때 "확인되지 않은 앱" 경고만 뜹니다.
5. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **데스크톱 앱** (꼭 이것으로)
   - 만들기 → **JSON 다운로드** → `client_secret_....json` 파일이 받아집니다.
6. 위젯 실행(`npm start` 또는 exe) → **① JSON 파일 불러오기** → 방금 받은 파일 선택
7. **② 구글 로그인** → 브라우저가 열림 → 계정 선택
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (앱 이름)(으)로 이동(안전하지 않음)** → 캘린더 권한 **허용**
   - "연결 완료" 문구가 보이면 브라우저 탭을 닫고 위젯으로 돌아오면 됩니다.

### 비밀 값 관리 (중요)

- 받은 JSON 파일과 로그인 토큰은 **채팅, 메일, 메신저, 깃허브 등에 절대 붙여넣거나 올리지 마세요.**
- 위젯은 이 정보를 윈도우 계정 암호화(DPAPI, Electron safeStorage)로 PC 안에만 저장합니다.
  저장 위치: `%APPDATA%\calendar-widget\` (`secure.bin` 은 암호화된 파일)
- 불러오기가 끝났으면 다운로드 폴더의 JSON 파일은 지워도 됩니다(다시 필요하면 콘솔에서 새로 받을 수 있음).
- 이 폴더의 `.gitignore` 에 `client_secret*.json` 이 들어 있어 실수로 커밋되지 않게 막아 둡니다.
- 연결을 끊으려면 ⚙ 설정 → 로그아웃 (구글 쪽 권한도 함께 해제합니다).

## 3. 기관 업무용 PC에서 쓸 때 확인할 점

- 기관 보안 정책상 **프로그램 설치(Node.js)나 exe 실행이 막혀 있을 수 있습니다.** 이 경우 전산 담당자에게 먼저 확인하세요.
- 기관 구글 워크스페이스 계정이라면 관리자가 외부 앱 연결을 막아 두었을 수 있습니다(로그인 단계에서 오류). 개인 구글 계정은 해당 없음.
- 개인 일정과 업무 일정이 한 캘린더에 섞여 있다면, 공용 PC 화면에 보인다는 점을 고려하세요.

## 4. 알려진 한계

- 기본 캘린더(primary) 한 개만 보여 주고 고칩니다. 다른 캘린더(공유 캘린더, 대한민국 공휴일 등)는 아직 표시하지 않습니다.
- 일정 색상 변경, 참석자 초대, 반복 규칙 만들기/수정은 위젯에서 지원하지 않습니다(구글 캘린더에서 하세요).
- 인터넷이 끊기면 일정을 불러오지 못합니다(오프라인 저장 없음).
- 윈도우 "바탕화면에 고정(다른 창 아래에 항상 깔림)" 기능은 Electron에서 공식 지원하지 않아 넣지 않았습니다. 대신 일반 창 / 항상 위 중에서 고를 수 있습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `main.js` | 창 만들기, 설정 저장, 자동 실행, 화면과 통신 |
| `preload.js` | 화면에서 쓸 수 있는 기능만 골라서 연결 |
| `src/google.js` | 구글 로그인(OAuth + PKCE, 127.0.0.1 루프백)과 캘린더 API 호출 |
| `src/eventFormat.js` | 화면용 일정 ↔ 구글 일정 형식 변환, 입력 검사 |
| `src/store.js` | 일반 설정(settings.json)과 암호화 저장(secure.bin) |
| `src/demo.js` | `npm run demo` 용 테스트 데이터 |
| `app/` | 화면 (index.html, style.css, app.js) |
