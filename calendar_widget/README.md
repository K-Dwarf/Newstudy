# 바탕화면 캘린더 위젯 (구글 캘린더)

윈도우 바탕화면에 띄워 두는 작은 캘린더 창입니다. 구글 캘린더와 직접 연결되어
위젯에서 **일정 추가 · 수정 · 삭제**를 하면 휴대폰 구글 캘린더에도 바로 반영되고 알림도 그대로 옵니다.

> "크리스마스 댄스 연습실" 프로그램과는 별개의 독립된 프로그램입니다. 코드나 설정을 공유하지 않습니다.

## 기능

- **월 / 주 / 오늘 탭**: 처음엔 월 달력, 위쪽 탭으로 바꿀 수 있습니다. `‹ ›`로 이동, `오늘`로 복귀 (키보드 ← → 도 됨)
- **빠른 추가** (아래 입력칸, 선택한 날짜에 들어감)
  - `14:00 회의`, `오후 2시 30분 방문`, `2시반 상담` → 1시간짜리 일정
  - `내일 9시 교육`, `모레 보고서 마감` → 내일/모레 날짜로
  - 시간이 없으면 종일 일정
  - 오전/오후 없이 1~7시라고 쓰면 **오후**로 봅니다. 새벽이면 `오전 5시` 또는 `05:00`처럼 쓰세요.
- **일정 수정 / 삭제**: 일정을 누르면 제목, 종일 여부, 날짜, 시간, 메모, 알림(10분 전, 1시간 전, 하루 전 등)을 바꾸거나 삭제할 수 있습니다.
  - 반복 일정은 누른 그 날짜 하나만 바뀌거나 지워집니다. 반복 전체를 바꾸려면 "구글에서 열기"를 누르세요.
- **대한민국 공휴일 표시**: 구글의 "대한민국의 휴일" 공개 캘린더를 읽어 날짜를 빨간색으로 칠하고 이름을 보여 줍니다.
  설·추석·대체공휴일처럼 해마다 바뀌는 날도 구글이 올려 둔 대로 나옵니다. 설정(⚙)에서 끌 수 있습니다.
  어버이날처럼 쉬는 날이 아닌 기념일은 회색 글씨로만 표시합니다(구글 일정 설명의 "기념일" 표시로 구분하며, 실제 데이터로는 아직 확인 못 함).
- 월 달력에서 날짜를 **두 번 클릭**하면 그 날짜에 새 일정 추가
- 5분마다, 그리고 위젯을 다시 클릭할 때 자동 새로고침
- **바탕화면에 고정 (윈도우, 기본으로 켜짐)**: 위젯이 다른 프로그램 창과 폴더 창보다 항상 뒤에 깔립니다.
  위젯을 클릭해도 앞으로 튀어나오지 않고, 클릭과 입력은 그대로 됩니다.
  - 고정 중에는 작업표시줄에 안 보입니다. 화면 오른쪽 아래 **알림 영역(트레이)의 캘린더 아이콘**을 누르면
    잠깐 앞으로 나오고, 다른 곳을 클릭하면 다시 뒤로 갑니다. 아이콘을 오른쪽 클릭하면 고정 해제와 종료가 있습니다.
    (아이콘이 안 보이면 작업표시줄 오른쪽의 `^` 를 눌러 보세요.)
  - 바탕화면 아이콘보다 뒤로 보내는 것은 클릭이 안 되게 되므로 하지 않았습니다. 아이콘이 없는 곳에 두세요.
  - ⚙ 설정에서 끄거나 "항상 위에 표시"로 바꿀 수 있습니다(둘 중 하나만).
- **투명도 (🎨 버튼)**: "배경 투명도"는 글자는 그대로 두고 바탕만 투명하게, "창 전체 투명도"는 글자까지 함께 흐리게 합니다.
  - **프리셋**: 가독성 우선 / 균형 / 투명하게 를 한 번에 고를 수 있습니다.
  - **글자 뒤 받침 유지 (가독성 보호, 기본 켜짐)**: 바탕을 투명하게 하거나 배경 이미지를 깔아도 달력·일정 글자 뒤에
    반투명 받침을 남겨서 글자가 묻히지 않게 합니다. 끄면 바탕화면이 더 많이 보이는 대신 글자 그림자만 남습니다.
- **일정 색**: 구글 캘린더에서 정한 일정 색과 내 캘린더 색을 그대로 씁니다. 색 칩의 글자는 배경색에 따라
  흰색/어두운 색 중 더 잘 보이는 쪽으로 자동으로 바뀝니다. 달력 칸에서는 한 줄(넘치면 …), 아래 목록에서는 최대 2줄로
  보이고, 마우스를 올리면 전체 제목이 보입니다.
- **키보드**: Tab 으로 버튼·날짜 칸·일정을 옮겨 다닐 수 있습니다(파란 테두리 표시). 날짜 칸에서 Enter 는 선택,
  Shift+Enter 는 그 날짜에 일정 추가, 일정에서 Enter 는 수정 창 열기.
- **꾸미기 (🎨 버튼)**: jpg · jpeg · png · gif · webp 이미지를
  - **배경 이미지**로 깔기: 진하기, 어둡게(글자 잘 보이게), 맞춤 방식 조절
  - **스티커**로 붙이기 (여러 장, 최대 40개). **움직이는 GIF·WebP 캐릭터도 그대로 움직입니다.**
    - 붙이는 방법: ① 탐색기에서 이미지 파일을 위젯으로 **끌어다 놓기** ② 복사한 이미지·캡처를 **Ctrl+V**
      ③ 🎨 → "＋ 이미지 붙이기". 붙이면 바로 편집 상태가 됩니다.
    - 편집 (🎨 → "스티커 편집"): 스티커를 눌러 선택 → 끌어서 이동, 오른쪽 아래 □ 로 크기, 위쪽 ○ 로 회전(Shift: 15°씩)
    - 도구 막대: 뒤집기, 회전 초기화(↺), 복제, 다른 스티커보다 맨 앞/맨 뒤, 글자 앞/뒤, 투명도, 삭제
    - 단축키: Ctrl+Z 되돌리기, Ctrl+Y 다시 하기, Ctrl+D 복제, Delete 삭제, 방향키로 1px(Shift: 10px) 이동, Esc 선택 해제/편집 끝
    - **📅 날짜에 붙이기**: 월 탭에서 스티커를 날짜 칸 위에 놓고 누르면 그 날짜에 붙어서, 달을 넘겨도 그 날짜를 따라다닙니다.
      주/오늘 탭에서는 그 날짜 제목 옆에 작게 보입니다. 날짜 스티커는 칸 크기에 맞춰 커지고 작아집니다.
    - 날짜에 붙이지 않은 스티커는 위젯 크기를 바꾸면 위치와 크기가 비율대로 따라갑니다.
    - 편집을 마치면(완료) 스티커가 달력 클릭을 막지 않습니다.
  - 고른 이미지는 `%APPDATA%\CalendarWidget\decor\` 에 복사돼서 원본을 옮기거나 지워도 그대로 보입니다(30MB 이하).
- 설정(⚙): 구글 연결, 공휴일 표시, 윈도우 시작 시 자동 실행, 바탕화면 고정 / 항상 위에 표시(📌)
- 창 위치와 크기는 기억됩니다. 제목줄을 끌어서 옮기고, **오른쪽 아래 모서리의 빗금 손잡이**를 끌어서 크기를 바꿉니다.

## 정식 버전 만들기 · 설치 (처음 한 번)

순서: **① 구글 설정 → ② 코드 받기 → ③ 설치 파일 만들기 → ④ 설치 → ⑤ 로그인.** 한 번만 하면 됩니다.

설치하고 나면:
- 컴퓨터를 켜면 위젯이 **자동으로 켜집니다**(처음 실행할 때 자동으로 등록, ⚙ 설정에서 끌 수 있음).
- **한 번 로그인하면** 컴퓨터를 껐다 켜도 로그인 상태가 유지됩니다(구글 동의 화면이 "프로덕션"일 때. ① 4번 참고).
- 컴퓨터를 막 켜서 인터넷이 아직 안 붙었으면, 연결되는 대로 알아서 다시 불러옵니다(30초마다 재시도).

### ① 구글 설정 (약 10분)

위젯이 구글 캘린더에 접근하려면 "앱 등록증"(OAuth 클라이언트)이 필요합니다.
구글 화면 문구는 바뀔 수 있어 아래 이름과 조금 다를 수 있습니다.

1. https://console.cloud.google.com/ 에 로그인합니다(등록증 관리용 계정, 보통 내 구글 계정).
2. 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 예: `calendar-widget` → 만들기 → 만든 프로젝트 선택
3. **☰ → API 및 서비스 → 라이브러리** → `Google Calendar API` 검색 → **사용**
4. **☰ → API 및 서비스 → OAuth 동의 화면**("Google 인증 플랫폼") → 시작하기
   - 앱 이름: `캘린더 위젯`, 사용자 지원 이메일: 내 이메일, 대상: **외부**, 연락처 이메일: 내 이메일
   - **대상(Audience)** 메뉴에서 **게시 상태를 "프로덕션"(앱 게시)** 으로 바꿉니다. ← **중요**
     "테스트" 상태로 두면 **7일마다 로그인이 풀립니다.**
     프로덕션이어도 구글 심사 없이 쓸 수 있고, 로그인할 때 "확인되지 않은 앱" 경고만 뜹니다.
   - 다른 사람에게 줄 경우: 그 사람들 로그인 화면에도 **앱 이름과 지원 이메일**이 보입니다.
5. **☰ → API 및 서비스 → 클라이언트**(또는 사용자 인증 정보) → **클라이언트 만들기**(OAuth 클라이언트 ID)
   - 애플리케이션 유형: **데스크톱 앱** (꼭 이것으로)
   - 만들면 뜨는 창에서 **바로 "JSON 다운로드"** (창을 닫으면 비밀번호를 다시 안 보여 줄 수 있음)
   - `client_secret_....json` 파일이 받아집니다. **채팅·메일·깃허브 등에 올리지 마세요.**

### ② 코드 받기

이 위젯 코드는 `claude/calendar-widget` 브랜치에 있습니다.

- **ZIP**: https://github.com/K-Dwarf/Newstudy/tree/claude/calendar-widget → 초록색 **Code** → **Download ZIP** → 압축 풀기.
  풀린 폴더 안의 `calendar_widget` 폴더가 위젯입니다.
- **git**: `git clone -b claude/calendar-widget https://github.com/K-Dwarf/Newstudy.git` (업데이트는 `git pull`)

### ③ 설치 파일 만들기 (내 PC에서)

PC에 [Node.js](https://nodejs.org/) (LTS)가 있어야 합니다(이 단계에서만 필요. 설치해서 쓰는 사람은 필요 없음).

1. ①에서 받은 `client_secret_....json` 을 **`calendar_widget` 폴더 안에 복사**합니다(하나만).
2. PowerShell 또는 명령 프롬프트에서:

```bat
cd "calendar_widget 폴더 경로"
npm install
npm run dist
```

3. 몇 분 뒤 `calendar_widget\dist\CalendarWidget-Setup-1.0.0.exe` 가 생깁니다.
   - 화면에 `[완료] 등록증을 내장합니다` 가 나오면 JSON 이 설치 파일 안에 들어간 것입니다.
     그래서 설치한 사람은 JSON 없이 **"구글 로그인"만 누르면** 됩니다.
   - JSON 원본과 내장용 파일(`embedded-client.json`)은 `.gitignore` 에 있어 깃허브에 올라가지 않습니다.
     JSON 원본은 안전한 곳에 보관하세요(다음에 다시 빌드할 때 필요).
   - JSON 없이 `npm run dist` 하면 등록증 없이 만들어지고, 설치한 사람이 ⚙ 설정에서 JSON 을 직접 불러와야 합니다.
   - PowerShell 에서 `npm` 이 막히면 `npm.cmd` 로 쓰세요.
   - 처음 빌드할 때 설치 파일 제작 도구를 인터넷에서 내려받습니다. 기관 네트워크에서 막히면 집이나 개인 PC에서 해 보세요.

### ④ 설치

1. `CalendarWidget-Setup-1.0.0.exe` 를 실행합니다. 관리자 권한 없이 내 사용자 폴더에 설치됩니다.
2. **"Windows의 PC 보호"(파란 창)** 가 뜨면 **추가 정보 → 실행**. (전자 서명을 안 한 프로그램이라 뜨는 경고입니다.)
3. 설치가 끝나면 위젯이 바로 켜지고, 바탕화면과 시작 메뉴에 **"캘린더 위젯"** 바로 가기가 생깁니다.

### ⑤ 로그인

1. 위젯의 **구글 로그인** → 브라우저가 열리면 내 구글 계정 선택
2. "Google에서 확인하지 않은 앱" 이 나오면 **고급 → 캘린더 위젯(으)로 이동(안전하지 않음)**
3. 권한 두 개(일정 보기·수정, 캘린더 보기)를 **모두 체크** → 계속 → "연결 완료"가 보이면 브라우저 탭을 닫습니다.

끝입니다. 이제 컴퓨터를 켤 때마다 로그인된 상태로 위젯이 바탕화면에 나타납니다.

### 업데이트 · 삭제

- **업데이트**: 새 코드를 받아 `package.json` 의 `"version"` 을 올리고(예: 1.0.1) ③을 다시 → 새 설치 파일 실행.
  로그인, 꾸미기, 설정은 그대로 남습니다.
- **삭제**: 윈도우 **설정 → 앱 → 설치된 앱 → 캘린더 위젯 → 제거**. 자동 실행 등록도 같이 지워집니다.
  로그인 정보·꾸미기(`%APPDATA%\CalendarWidget\`)는 남겨 두니, 완전히 지우려면 그 폴더도 지우세요.

## 다른 사람에게 주기

- ③에서 만든 **`CalendarWidget-Setup-1.0.0.exe` 하나만** 주면 됩니다. 받는 사람은 ④ 설치 → ⑤ 로그인만 하면 됩니다.
- 받는 사람은 **자기 구글 계정**으로 로그인하고, 일정은 그 사람 PC와 구글 사이에서만 오갑니다. 만든 사람은 볼 수 없습니다.
- 조건과 주의점
  - 구글 심사를 받지 않은 앱이라 로그인 때 "확인되지 않은 앱" 경고가 뜨고, 쓸 수 있는 사람 수에 제한이 있습니다
    (구글 정책상 약 100명. 정책은 바뀔 수 있음). 동의 화면이 "테스트" 상태라면 받는 사람 이메일을
    테스트 사용자로 하나씩 추가해야 하고 7일마다 다시 로그인해야 하니, 꼭 "프로덕션"으로 두세요.
  - 설치 파일 안의 등록증은 마음먹으면 꺼낼 수 있습니다. **믿을 수 있는 사람에게 직접**(메신저·USB 등) 주고,
    인터넷 공개 장소(깃허브, 공개 카페 등)에는 올리지 마세요.
  - 기관 구글 워크스페이스 계정은 관리자가 외부 앱을 막아 로그인이 안 될 수 있습니다(개인 구글 계정은 괜찮음).
  - 받는 사람이 자기 등록증을 쓰고 싶으면 ⚙ 설정 → "다른 등록증(JSON) 불러오기".
- 같은 PC에서 **윈도우 사용자 계정**이 다르면 각자 따로 로그인하고 설정도 따로 저장됩니다.
  한 위젯에 구글 계정은 하나만 연결됩니다(바꾸려면 로그아웃 후 다른 계정으로 로그인).

## 개발용 실행 (설치 없이)

```bat
npm install
npm run demo   :: 테스트 데이터로 화면만 확인 (구글 연결 없음)
npm start      :: 실제 구글 캘린더 연결 (등록증 JSON 은 ⚙ 설정에서 불러오기, 또는 ③처럼 폴더에 두고 npm run dist 한 뒤)
```
개발용 실행에서는 "윈도우 시작 시 자동 실행"을 켤 수 없습니다(설치한 프로그램에서만).

## 비밀 값 관리 (중요)

- 받은 JSON 파일과 로그인 토큰은 **채팅, 메일, 메신저, 깃허브 등에 절대 붙여넣거나 올리지 마세요.**
- 위젯은 이 정보를 윈도우 계정 암호화(DPAPI, Electron safeStorage)로 PC 안에만 저장합니다.
  저장 위치: `%APPDATA%\CalendarWidget\` (`secure.bin` 은 암호화된 파일)
- JSON 원본은 설치 파일을 다시 만들 때 필요하니 안전한 곳에 보관하세요(잃어버리면 콘솔에서 새로 만들 수 있음).
- 이 폴더의 `.gitignore` 에 `client_secret*.json`, `embedded-client.json` 이 들어 있어 실수로 커밋되지 않게 막아 둡니다.
- 연결을 끊으려면 ⚙ 설정 → 로그아웃 (구글 쪽 권한도 함께 해제합니다).

## 기관 업무용 PC에서 쓸 때 확인할 점

- 기관 보안 정책상 **프로그램 설치나 서명 안 된 exe 실행이 막혀 있을 수 있습니다.** 이 경우 전산 담당자에게 먼저 확인하세요.
- 기관 구글 워크스페이스 계정이라면 관리자가 외부 앱 연결을 막아 두었을 수 있습니다(로그인 단계에서 오류). 개인 구글 계정은 해당 없음.
- 개인 일정과 업무 일정이 한 캘린더에 섞여 있다면, 공용 PC 화면에 보인다는 점을 고려하세요.

## 알려진 한계

- 내 일정은 기본 캘린더(primary) 한 개만 보여 주고 고칩니다. 공휴일 외의 다른 캘린더(공유 캘린더 등)는 아직 표시하지 않습니다.
- 공휴일은 구글 공개 캘린더에서 받아 오므로 인터넷 연결과 로그인이 필요합니다. `npm run demo`의 공휴일은 매년 날짜가 같은 양력 공휴일 몇 개만 넣은 테스트용입니다.
- 일정 색상 변경, 참석자 초대, 반복 규칙 만들기/수정은 위젯에서 지원하지 않습니다(구글 캘린더에서 하세요).
- 인터넷이 끊기면 일정을 불러오지 못합니다(오프라인 저장 없음).
- 바탕화면 고정은 Electron 기본 기능이 아니라 윈도우 기능(user32)을 직접 불러 구현했습니다(koffi 사용).
  윈도우 10/11 버전에 따라 Win+D(바탕화면 보기)를 눌렀을 때 위젯이 잠깐 사라졌다가 돌아오거나, 사라진 채로 있을 수 있습니다(실제 윈도우에서 아직 확인 못 함).
  이상하면 트레이 아이콘을 누르거나 ⚙ 설정에서 고정을 끄세요.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `main.js` | 창 만들기, 설정 저장, 자동 실행, 화면과 통신 |
| `preload.js` | 화면에서 쓸 수 있는 기능만 골라서 연결 |
| `src/google.js` | 구글 로그인(OAuth + PKCE, 127.0.0.1 루프백)과 캘린더 API 호출 |
| `src/eventFormat.js` | 화면용 일정 ↔ 구글 일정 형식 변환, 입력 검사 |
| `src/store.js` | 일반 설정(settings.json)과 암호화 저장(secure.bin) |
| `src/demo.js` | `npm run demo` 용 테스트 데이터 |
| `src/desktopPin.js` | 바탕화면 고정 (윈도우 user32 호출) |
| `src/decor.js` | 배경 이미지·스티커 파일 복사/저장, `decor://` 주소로 화면에 전달 |
| `app/decor-ui.js` | 투명도·배경 이미지·스티커 편집 화면 |
| `assets/` | 프로그램·트레이 아이콘 |
| `scripts/prepare-client.js` | 설치 파일을 만들 때 등록증 JSON 을 프로그램에 내장 |
| `build/installer.nsh` | 설치 프로그램 추가 동작 (제거할 때 자동 실행 등록 정리) |
| `app/` | 화면 (index.html, style.css, app.js) |
